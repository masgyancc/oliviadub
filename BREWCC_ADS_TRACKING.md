## How it works
```
click â†’ link middleware (unchanged: cache lookup, click recorded in Tinybird, final URL chosen)
      â†’ link has enabled tags AND visitor is not a bot?
          yes â†’ internal rewrite to /ads-tracking/<workspaceId>/<linkId>/<finalUrl>

```
- Links without tags behave exactly as before. The only addition is one Redis read per click (`ads-tracking:<linkId>`, an empty list is cached too).
- Bots and link-preview crawlers always get the direct redirect.
- The click is recorded once, before the interstitial, so BrewCC analytics are unchanged.
- The interstitial can't be opened directly: every public path on a short-link domain is resolved as a link first, and the app domain rewrites everything to `/app.dub.co/â€¦`. The destination must be http(s).
- Tags only fire while the link stays in the workspace that configured them (cache query is scoped by `linkId` + `projectId`).

## API (same auth as the links API: `withWorkspace`)
| Method | Path | Permission |
|---|---|---|
| GET | `/api/links/[linkId]/tracking` | `links.read` |
| POST | `/api/links/[linkId]/tracking` `{mode:"manual", platform, pixelId, conversionLabel?, name?}` or `{mode:"code", platform, code, name?}` | `links.write` |
| PATCH | `/api/links/[linkId]/tracking/[tagId]` `{enabled?, name?, pixelId?, conversionLabel?}` | `links.write` |
| DELETE | `/api/links/[linkId]/tracking/[tagId]` | `links.write` |

Each request checks: approved user, workspace membership + role, `getLinkOrThrow(workspace, linkId)`, folder permission. Every tag query is scoped by `linkId` and `projectId`, so tags can't be read or changed across links or users. Limits: 10 tags per link; root domain links can't have tags. Duplicate IDs are rejected.

## Known limits
- Tagged links take about 1.2 s longer on the first visit. Ad-blockers and iOS privacy may block pixel requests, but the redirect still happens.
- Platform events are PageView (Meta), page (TikTok) and config/conversion (Google). Custom events are out of scope for phase 1.
- The Vercel Firewall challenge still runs before the interstitial on short-link domains.
